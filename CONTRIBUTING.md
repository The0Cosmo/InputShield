# Contributing

Thanks for helping improve InputShield.

## Before submitting

- Describe the exact Windows version/build and architecture.
- Include reproducible steps and expected vs. actual behavior.
- State whether the test used keyboard, mouse, Raw Input, DirectInput, XInput, or HID.
- Do not claim background-process isolation unless you have a repeatable test proving it.
- Keep changes focused and document limitations.

## Safety

InputShield is experimental. Avoid adding kernel drivers, services, or privilege elevation without a documented threat model, review, and explicit user consent.
