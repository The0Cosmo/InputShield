# Security Policy

## Project status

InputShield is experimental and is not production-ready. Do not use it as a security boundary or as a guarantee that another process cannot receive input.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Contact the repository maintainer privately through the GitHub profile and include:
- affected version/commit;
- Windows version and architecture;
- reproducible steps and expected/actual behavior;
- logs or a minimal proof of concept, with secrets removed.

Do not include personal data or unrelated system information.
